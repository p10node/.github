## ⭐ k10s — the Kubernetes terminal UI you can *click*

[**github.com/p10node/k10s**](https://github.com/p10node/k10s) — a TUI that treats the mouse and the keyboard as equals. Actions are on screen, not in your memory.

```sh
curl -fsSL https://p10node.com/k10s/install.sh | sh
```

- **16 resource kinds** across Workloads, Network, Config, Storage and Cluster, with live row counts
- **Day-2 toolkit** — describe, YAML, follow logs, shell in, port-forward, metrics, edit, restart, scale, delete
- **One search box for the whole cluster** — resource kinds and objects in the same result list
- **AI prompt with cluster context** injected, so the answer knows what is actually running
- **Seven themes** — Tokyo Night, Catppuccin, Dracula, Nord, Gruvbox, Solarized Light, Matrix
- **Self-updating binary** with checksum verification, plus an offline demo mode
- Go 1.26+ · Apache-2.0 · coming from k9s? The keymap is in the README

> If you live in `kubectl`, this is the one repo of ours to star.
